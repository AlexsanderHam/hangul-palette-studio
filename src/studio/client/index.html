WORKSPACE GUIDE

Studio 사용하기

색상을 고르고 실제 컬러 폰트를 확인하는 로컬 제작 도구입니다.

색을 고르고 미리보기를 확인하세요

Studio를 열면 현재 소스에 맞는 폰트를 자동으로 준비합니다. 이미 준비된 폰트는 다시 사용합니다. Thin부터 Black까지 아홉 굵기를 비교하거나 한 글자 비교로 원하는 한글을 확인하세요. 색상은 폰트를 다시 만들지 않고 바로 바뀝니다.

폰트의 기본색은 검정입니다. 선택한 색상은 미리보기와 CSS에 적용됩니다. 한글의 세부 영역은 영역별 색상으로, 영문·숫자·기호는 일반 CSS color로 색칠합니다.

웹에서 사용하기

폰트 다운로드로 WOFF2 아홉 종, 현재 색상의 CSS, 미리보기와 라이선스를 ZIP으로 받습니다. 색상만 바꿀 때는 CSS만 다운로드를 이용하세요. CSS와 WOFF2를 같은 폴더에 두고 hangul-palette 클래스를 적용하면 됩니다.

저장과 복원

색상 변경은 로컬 작업본에 자동으로 저장됩니다. 저장되지 않은 색상은 팔레트의 변경 버리기로 취소하고 저장된 팔레트로 돌아갈 수 있습니다. 서버에 보낸 변경이 보류된 경우에는 상단 안내에서 다시 시도하거나 버려 주세요.

저장된 변경은 팔레트 옆의 실행 취소·다시 실행과 작업 정보 → 백업 복원을 이용하세요. 한 번에 한 탭에서 색상을 편집합니다.

Ctrl/⌘ Z로 실행 취소, Ctrl/⌘ Shift Z로 다시 실행합니다. 텍스트 입력 중에는 입력 내용에 대한 기본 단축키가 작동합니다.
